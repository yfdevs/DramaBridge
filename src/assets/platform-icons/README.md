# Official platform icons

Downloaded from official platform pages and their linked first-party asset hosts on 2026-10-20. The Huolong icon is the artwork published by Tencent on its official App Store listing. Each filename matches the platform ID.

ICO/JPEG files are converted to PNG for consistent browser rendering. Original colors and geometry are preserved, with no recoloring, masks, filters, or redrawing. All files are imported through `index.ts` and bundled locally; the app makes no runtime requests to third-party icon services.
