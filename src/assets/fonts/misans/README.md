# MiSans global UI font

DramaBridge uses **MiSans**, designed and distributed by Xiaomi, as its global UI font. Its clean Chinese sans-serif forms provide a desktop reading style similar to PingFang without requiring Apple system fonts.

- Official website: https://hyperos.mi.com/font/zh/
- Original download: https://hyperos.mi.com/font-download/MiSans.zip
- License: `LICENSE.pdf`, downloaded unchanged from the official font license link.
- Included official WOFF2 files: Regular (400), Medium (500), Demibold (600), Bold (700).

Downloaded on 2026-10-20. Font binaries are unmodified. `fonts.css` maps the original files to their respective CSS weights. All files are bundled locally and work offline; there are no requests to an external font CDN. MiSans attribution is retained here with the original license.
