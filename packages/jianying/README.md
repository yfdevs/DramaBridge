# 剪映工作台自动化

工具 → 剪映 → 选择整部剧目录 → 启动处理。Windows 剪映专业版 11.6.0.14552。

当前工作流以每集为主，不合并多集，不延长原片时长。

- 固定使用第 1–4 集，默认按 15–30 秒随机生成素材，按 CPU 核心数最多同时处理四集，使用 veryfast 编码，导入剪映素材面板。
- 导入后滚动读取素材列表并按文件名批量核对，不执行文字搜索；原片必须完整显示在素材面板内，选中后刷新加入按钮，再核对唯一入轨结果。
- 每集完整源视频加入底层主轨，只切少量长短不一的切口。
- 从主轨复制视频块，默认每次随机生成 8–14 个，混排明显的短块与长块，错开放在字幕与主视频之间的两轨，覆盖前、中、后不同位置；数量范围可在工具页调整。
- 在剪映中分离原声和识别中文字幕；原声切段后随机复制，默认音频总块数为 20–40 个，范围可调整，每个副本单独裁短且最长 15 秒，铺满前中后并穿插少量重叠，音轨数随重叠排布变化。
- 顶部添加少量可用特效；任务结束和截图时保持素材面板可见。
- 每集随机筛选 4 个不同时间点，优先检出人脸的源画面，展开时间线后保存剪映窗口截图。

每次启动重新生成切点、复制块数量及位置、重复音频位置、特效位置和截图时间点；任务计划保留剪辑切点及复制块、音频的位置，截图目录另有时间点记录。

首次运行自动准备 Python、UIA、Pillow 和 OpenCV 环境。运行期间保持桌面解锁，并等待完成后再操作剪映。取消或失败时保留已生成片段和草稿，不修改源视频。重复音频按要求允许重叠，结果保留为可继续编辑的工程。

输出位于视频目录下独立的“剪映素材-…”文件夹。每集截图子目录包含 4 张窗口截图和记录各时间点及源画面人脸检测结果的 JSON。素材配置存储使用 electron-store；任务计划 JSON 是每次任务的产物，不作为配置缓存。

实现边界：使用 UIA 控件定位和经过定位的鼠标键盘操作。素材、视频数量、原声分割、主轨时长、跨轨复制及截图分别检查；字幕识别的密集轨道在缩小显示时还需结合界面像素确认。特效资源不可用时记录原因，不把未添加的资源计为成功。其他剪映版本和自定义布局仍需要实测。


四集素材只准备一次，每集创建独立草稿，原片和共享素材在每次导入前重新洗牌；截图统一保存于输出目录的 `截图/第01集` 至 `截图/第04集`。逐集完成记录会立即保存，失败或取消保留已完成的草稿与截图。

## 多任务队列

剪映工具的“任务队列”标签页按添加顺序逐部处理，列表沿用工作台的紧凑表格结构，支持搜索、状态筛选、查看结果、移除与失败重试。

先在“自动处理”中设置素材时长、视频及音频片段范围，再切到“任务队列”添加剧集文件夹。每个任务保存添加时的配置。点击“启动队列”后一次仅执行一部剧；暂停队列允许当前剧完成，停止当前任务则同时暂停队列。失败后暂停剩余任务，重试后需要重新启动队列。

队列通过 electron-store 保存，重新打开应用后保留任务；中断中的任务恢复为等待，不自动操作剪映。结果入口按任务定位输出目录。
# 视频转文字（接口调用）

默认使用“多集识别”：选择直接包含视频的目录，自动读取全部视频和集数编号，
支持阿拉伯数字、EP 和中文集数。未识别集号的文件自动分配空余编号，并提示核对。
用户可以修改每集编号、识别集数及勾选范围，点击“开始识别”才会调用剪映。
重复编号会阻止启动，避免字幕覆盖。

字幕统一保存到全局运行数据目录下的 `jianying/字幕/`，Windows 未配置时默认使用
`D:\.drama-runs\jianying\字幕\`，磁盘不可用则使用用户数据目录下的 `.drama-runs`。
单集与多集都不在项目内生成文件，任务开始时读取最新全局目录配置。
多集任务按集号顺序处理，在一个独立任务目录集中生成 `第01集.srt`、`第01集.txt` 等文件；
原始识别记录保存在同目录的“识别记录”子目录。某一集失败时继续后续集，
停止识别保留已经完成的文件。单视频识别仍可切换使用。

剪映工具中的“选择视频并识别”会打开文件选择器，使用本机剪映安装目录中的
`vebun.exe` 启动 `lyra-cli.exe media asr`，复用剪映账号认证及字幕识别权益。
无需配置 token，不操作剪映 UI，不读写时间线或草稿。原有剧集队列仍使用其原有流程。

识别前执行 `auth status` 检查登录。成功后在运行数据目录的
`jianying/字幕/<任务ID>/` 保存 UTF-8 BOM 的 TXT、SRT 及 CLI 原始 JSON，
页面可预览、复制全文、另存文件和打开结果目录。SRT 时间来自接口返回的
`start_us` 与 `duration_us`。任务最长 10 分钟，停止时终止整个识别进程树。

当前已在 Windows、剪映 11.8.0.14778 实测：直接启动 CLI 会拒绝宿主进程，
通过同目录的剪映 Bun 运行时启动可正常认证和识别。未来剪映版本可能改变内部接口；
安装组件缺失、未登录、会员权限不足及返回格式变化会明确报错。
